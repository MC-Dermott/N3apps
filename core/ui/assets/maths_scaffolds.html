Bus stop division with decimals

Generates a division question, then walks pupils through it column by column: how many go in, how many left over, exchange, repeat — down into the decimal places.

Pupils will type the divisor and the number itself straight into the empty bus stop.

Toggle the times table on the right for a quick reference of the divisor's multiples, just like jotting them down before starting.

Chimney sum subtraction

Generates a subtraction question, or lets pupils build their own, then walks through it column by column — pressing the small arrows to exchange a ten whenever a column needs one.

Click the column you want to start with, then tap the small arrow above a digit in the top number to exchange a ten into the column on its right.

Chimney sum addition

Generates an addition question, or lets pupils build their own, then walks through it column by column, right to left — with a space above each column to carry a ten into the next one.

Always start with the units column on the right. When a column totals 10 or more, carry the ten into the small box above the next column.

L-shape perimeter

Generates an L-shaped diagram with two sides missing, or lets pupils build their own — work out the missing sides first, then add all six sides to find the perimeter.

Work out the two missing sides first and type them straight onto the diagram, then add all six sides together to find the perimeter.

Time conversion

Generates a random time — decide whether the hour needs to change to convert it, then write the converted time.

Work out whether the hour needs to change first, then write the time in its new form.

Highest common factor

Build a factor T-table for each number — testing 1, 2, 3… in turn — then spot the biggest factor they all share.

Test each number in turn: is it a factor? If yes, find its pair. Keep going until the table meets itself in the middle, then compare the lists.
